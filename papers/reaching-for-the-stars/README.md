# Reaching for the Stars · 追逐星辰

九年级上册英语 Unit 6 Section B 阅读课件，对应所提供教材照片第 147–148 页。收录读前活动 1a、1b 和完整四段课文。课件配有中文参考译文、四幅段落插图、词句讲解、14 个语言点拓展、四道随堂语言练习、原文数据对数图、三道选择题及一个科普写作任务。参考答案用于课堂讲解。

- [在线课件](https://yogattt.github.io/english-classroom/papers/reaching-for-the-stars/)
- 下载或双击 `index.html` 即可离线授课，插画和脚本随页面内嵌。
- 点击段号或讲解区的段落按钮切换讲解和插图。插图可放大，译文和参考答案可显隐，原文和讲解字号可独立调节。
- 每段的「语言点拓展」包含原文用法、新例句和一题改写或迁移练习，可用「展示参考答案」查看参考写法。
- 「教师打印」展开读前活动及语言点拓展，并在打印版中呈现全部译文、讲解、段落插图及参考答案。
- 封面及段落插图用 ImageGen 生成，为课堂说明场景所用的示意图。距离对比图的数值来自课文。

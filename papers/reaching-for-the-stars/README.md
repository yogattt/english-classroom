# Reaching for the Stars · 追逐星辰

九年级上册英语 Unit 6 Section B 阅读课件，对应所提供教材照片第 147–148 页。收录读前活动 1a、1b 和完整四段课文。课件添加了四段画布动画、中文参考译文、词句讲解、原文数据对数图、三道选择题及一个科普写作任务。参考答案用于课堂讲解。

- [在线课件](https://yogattt.github.io/english-classroom/papers/reaching-for-the-stars/)
- 下载或双击 `index.html` 即可离线授课，插画和脚本随页面内嵌。
- 点击段号或讲解区的段落按钮切换讲解及动画。每段动画可播放、暂停、重播或分步展示。译文、参考答案均可显隐，原文和讲解字号可独立调节。
- 「教师打印」展开读前活动，并在打印版中呈现全部译文、讲解、动画图解文字与参考答案。
- 封面为使用 ImageGen 生成的旅行者号卡通教学插画。距离对比图的数值来自课文。

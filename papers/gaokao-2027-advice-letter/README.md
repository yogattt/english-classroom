# 2027届高考英语 建议信写作

在线地址：https://yogattt.github.io/english-classroom/papers/gaokao-2027-advice-letter/

依据用户提供的《2027届高考英语一轮复习 建议信写作 讲义》扩充重编。包含12个单元：审题、结构、建议展开、功能句型、语法、原稿使用边界、3篇情境范文、话题迁移、12道练习、3个写作任务与自查。

所有范文和练习均为教学示例或参考表达，不是高考真题、官方范文或官方评分标准。约80词是本页训练设定，实际以题面要求为准。

## 内容修订

- 统一第二篇收信人为外教 Mr. Smith，修正原稿“给校长”的标题。
- 讲清 advice/advise、suggest doing/that、分词逻辑主语、倒装和并列结构。
- 区分语法正确与语境得体，说明 had better、Eventually、Only in this way 和催促回复的使用限制。
- 重写三篇范文，补充建议与理由的联系，限定环境保护建议的对象与行动主体。

## 授课功能

单个 HTML 内嵌样式与脚本，无外部字体、网络脚本或图片依赖。支持章节导航、字号调整、中文释义显隐、答案展开、投屏、打印、离线下载。写作区支持词数统计、浏览器本地保存和TXT导出，无服务端数据上传。

词数按英文词统计，缩写/连字符词计一词。范文统计正文，不含称呼与署名。打印会展开讲解和参考答案。

# 被动语态精讲与专项训练

在线授课：https://yogattt.github.io/english-classroom/papers/passive-voice-workshop/

面向九年级复习，含进阶拓展，建议分两课时各45分钟选讲。

## 内容范围

14个章节：情境导入、课前诊断、语用意义、基本结构、主动转被动、八类时态与情态结构、否定疑问、特殊结构、错因、解题策略、原稿练习、语篇、表达任务及教师备课。

基于用户提供的《被动语态精讲与专项训练.docx》重新组织并补充。完整保留原稿10道单选、12道单句填空、两篇各10空语篇，共42个练习点；新增30题，合计72个练习点，另含3项表达任务。题目未附考试出处或官方答案，标注为原稿练习与教学参考答案；语境多解处注明适用条件。

## 使用

单文件HTML，可下载离线使用，无外部字体、图片或脚本依赖。使用SVG与CSS微缩情境插画。

- 顶部目录切换章节；左右方向键翻节。
- A显隐全部答案，T开关当前节教师提示。
- 题目可单独揭晓解析；语篇支持原文空位与解析联动。
- 讲解、原文、解析字号独立调整。
- Aa菜单可预览完整学生/教师讲义，再使用浏览器打印或另存为PDF。没有预生成PDF下载。
- 课堂作答和练笔仅保留在当前页面内存，刷新会清空，不进入公共打印讲义。

原稿的own/make up、let/have与to、to blame等规则已修订；具体边界与参考依据见第14节。
